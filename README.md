# Ai-DnD – Автоматизированный ведущий для D&D 5e на базе LLM

Ai-DnD — это проект автоматизированного ведущего (Dungeon Master) для настольной ролевой игры Dungeons & Dragons 5-й редакции, построенный на базе LLM (Large Language Model) и оркестрации с помощью n8n. Игроки могут подключаться к игровой партии, создавать персонажей и взаимодействовать с игровым миром через чат, где роль ведущего выполняет ИИ.

## Архитектура проекта

Проект разворачивается локально с помощью Docker Compose и включает следующие компоненты:

- **Backend**: FastAPI (Python) — предоставляет REST API для всех функций приложения
- **Frontend**: React — веб-интерфейс для игроков
- **База данных**: PostgreSQL — хранение данных игры
- **Хранилище объектов**: MinIO (S3-совместимое) — хранение изображений, карт, аватаров
- **Движок LLM**: Ollama — запуск и управление локальными языковыми моделями
- **Оркестратор**: n8n — автоматизация workflow (обработка действий, начисление опыта и т.д.)
- **RAG-сервис**: Векторное хранилище на базе ChromaDB с интеграцией MinIO для семантического поиска по правилам D&D

## Предварительные требования

- Docker и Docker Compose
- Python 3.11+
- Node.js 18+
- Достаточно ресурсов для LLM: минимум 8 ГБ RAM, SSD

## Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone https://github.com/yourusername/Ai-DnD.git
```

2. Перейдите в директорию проекта:
```bash
cd Ai-DnD
```

3. Создайте файл окружения:
```bash
cp .env.example .env
```

4. Настройте переменные в `.env` файле (пароли, ключи и т.д.)

5. Соберите и запустите контейнеры:
```bash
docker-compose -f infrastructure/docker/docker-compose.yml up -d --build
```

6. Проверьте статус сервисов:
```bash
docker-compose -f infrastructure/docker/docker-compose.yml ps
```

## Доступ к сервисам

- **Фронтенд**: http://localhost:3000
- **Backend API**: http://localhost:8000
- **Backend Health**: http://localhost:8000/health
- **n8n Workflow Editor**: http://localhost:5678
- **MinIO Console**: http://localhost:9001
- **Ollama**: http://localhost:11434

## Использование

1. Откройте фронтенд в браузере
2. Создайте или подключитесь к существующей партии по ID
3. Создайте персонажа
4. Начните игровую сессию
5. Взаимодействуйте с ИИ-ведущим через чат
6. ИИ-ведущий будет использовать RAG-сервис для точного следования правилам D&D 5e

## Конфигурация LLM

Для работы с LLM необходимо загрузить модель через Ollama. Пример:

```bash
# Загрузка модели Llama2 13B
ollama pull llama2:13b

# Или загрузка специализированной модели для D&D
ollama pull wizard-vicuna-13b
```

В workflow n8n укажите имя загруженной модели.

## Разработка

### Backend

Backend написан на FastAPI. Для локальной разработки:

```bash
# Установка зависимостей
pip install -r backend/requirements.txt

# Запуск сервера
python backend/main.py
```

### Frontend

Frontend написан на React. Для локальной разработки:

```bash
# Установка зависимостей
cd frontend
npm install

# Запуск сервера разработки
npm start
```
